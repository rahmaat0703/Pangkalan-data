ℹ️ Informasi Laporan
Format Export

Semua data akan di-export dalam format Microsoft Excel (.xlsx) yang dapat dibuka dengan Microsoft Excel, Google Sheets, atau aplikasi spreadsheet lainnya.

Isi Laporan
  • Data Pegawai: NIP, Nama, Email, Jabatan, Role, Tanggal Bergabung
  • Data Izin: NIP, Nama Pegawai, Tanggal, Jam Keluar, Jam Kembali, Keterangan, Status, Catatan Admin
  • Data Konsultasi: Nama, Email, Nomor, Kategori Instansi, Nama Instansi, Keperluan, Status, Tanggal
  • Data Pelanggaran: NIP, Nama Pegawai, Jenis Pelanggaran, Tanggal, Deskripsi, Sanksi
Tips
  • Export dilakukan secara real-time dari database
  • Data yang di-export adalah data terbaru saat tombol download diklik
  • Simpan file excel dengan nama yang jelas untuk memudahkan pencarian
  • Gunakan fitur filter di Excel untuk analisis data lebih lanjut
